# Email Assist

Private, read-only inbox triage for Proton Mail Bridge. The app ranks emails
needing replies and presents scores, reasons, and text previews.

Configure your own browser origin, login, IMAP username, AI endpoint, database,
storage directories, and Docker networks through environment variables.
Keep credentials and runtime data outside Git. The IMAP client uses read-only
commands; bounded email previews are sent to the configured AI endpoint.

See the current README for setup and verification instructions.
